# COMSCA landing page

A responsive Next.js App Router landing page with a white and blue palette.

## Run locally

```sh
npm install
npm run dev
```

Open http://localhost:3000. Run `npm run build` for a production build and `npm run typecheck` to check TypeScript.

Content reference: https://comsca.worldvision.org.ph/about/
Contact and network links point to the existing COMSCA Network website. The illustration is an inline SVG, with no external image dependencies. Google Fonts supplies DM Sans and Manrope; local sans-serif fallbacks are provided.
